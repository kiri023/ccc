# 준비물/행동 추천 규칙표 (MVP 초안)

## 1) 날씨 입력값
- 현재 기온(°C)
- 체감온도(°C)
- 강수확률(%)
- 미세먼지/초미세먼지 등급
- 풍속(m/s)
- 자외선 지수(UV)

## 2) 추천 규칙 (초안)

| 조건 | 추천 | 사용자 메시지 예시 |
|---|---|---|
| 강수확률 >= 60% | 우산 | "비 올 확률이 높아요. 우산 챙겨요." |
| 초미세먼지 나쁨 이상 | 마스크 | "공기가 탁해요. 마스크 챙기면 좋아요." |
| 체감온도 <= 10°C | 겉옷 | "체감온도가 낮아요. 겉옷 추천해요." |
| 자외선 >= 높음 | 선크림 | "자외선이 강해요. 선크림 발라요." |
| 최고기온 >= 28°C | 물 | "더울 수 있어요. 물 챙겨요." |
| 강풍 >= 8m/s | 출발 시간 조정 | "바람이 강해요. 조금 일찍 출발해요." |

## 3) 우선순위
1. 안전/건강 관련 항목(우산, 마스크, 겉옷)
2. 컨디션/편의 항목(선크림, 물)
3. 행동 가이드(출발 시간 조정)

## 4) 출력 정책
- 최대 3개 카드만 노출
- 첫 카드에는 "오늘 핵심 한 줄" 포함
- 같은 추천은 1일 내 반복 문구를 변형
