# PRD 초안: 아침 루틴 브리프 위젯/앱

## 1. 제품 개요

### 제품 한 줄 정의
아침에 한 번 보면 오늘의 날씨, 필요한 준비물, 루틴에 맞는 추천 행동을 자동으로 알려주는 위젯 중심 서비스.

### 문제 정의
사용자는 아침에 날씨, 미세먼지, 체감온도, 일정 같은 정보를 여러 앱에서 따로 확인해야 한다. 이 과정은 번거롭고, 출근/등교 준비 시간에는 인지 부담이 크다. 결과적으로 우산, 마스크, 겉옷 같은 준비물을 놓치거나 오늘 하루의 컨디션을 미리 조정하지 못한다.

### 제품 목표
1. 아침에 꼭 열어보는 습관을 만든다.
2. 하루 3회 이상 자연스럽게 다시 열어보게 만든다.
3. 날씨 기반 준비물 추천을 넘어, 사용자의 하루 행동을 가볍게 유도한다.
4. 장기적으로는 위젯에서 앱으로 이동시키고, 앱에서 더 깊은 사용 습관을 만든다.

## 2. 타깃 사용자

### 1차 타깃
- 직장인
- 학생
- 아침 출근/등교처럼 루틴한 하루를 보내는 사람

### 사용자 특징
- 매일 아침 비슷한 시간대에 움직인다.
- 날씨와 옷차림, 준비물 판단을 자주 놓친다.
- 캘린더 연동에는 거부감이 있을 수 있다.
- 정보 자체보다 “오늘 뭘 하면 되는지”를 빠르게 알고 싶어 한다.

## 3. 핵심 인사이트

### 제품이 해결해야 하는 진짜 문제
사용자는 날씨를 보고 싶어서 앱을 여는 게 아니라, **오늘 챙겨야 할 것과 움직여야 할 방식을 빨리 알고 싶어서** 앱을 연다.

### 제품 방향
- 단순 정보 제공 앱이 아니라, 행동 추천 앱으로 간다.
- 처음에는 위젯이 메인이다.
- 이후 앱에서 개인화와 반복 사용 구조를 강화한다.
- 날씨 데이터만으로 시작한다.
- 캘린더 연동은 초기 범위에서 제외한다.

## 4. 제품 컨셉

### 핵심 컨셉
**“오늘 아침, 무엇을 챙기고 어떻게 움직여야 하는지 대신 판단해주는 아침 브리프”**

### 추천 콘텐츠 예시
- 비 확률 높음 → 우산 추천
- 미세먼지 나쁨 → 마스크 추천
- 기온 낮음 → 겉옷 추천
- 날씨가 좋음 → 바깥활동 추천 + 꽃/산책 같은 감성 요소 노출
- 아침 흐름이 여유로움 → 출근길에 볼 수 있는 콘텐츠 추천

## 5. 핵심 기능

### MVP 기능
1. **오늘 날씨 요약**
   - 현재 기온
   - 체감온도
   - 강수확률
   - 미세먼지/초미세먼지
   - 강풍/자외선(선택)
2. **준비물 추천 카드**
   - 우산
   - 마스크
   - 겉옷
   - 선크림
   - 물
   - 출발 시간 조정 안내
3. **아침 브리프 위젯**
   - 오늘의 핵심 한 줄
   - 준비물 아이콘
   - 짧은 행동 추천
   - 바로 열기 버튼
4. **하루 3회 이상 열어보게 하는 터치포인트**
   - 아침: 오늘 브리프
   - 이동/출근 전: 상황별 짧은 리마인드
   - 저녁: 오늘 요약 또는 내일 예고
5. **날씨 기반 감성 연출**
   - 좋은 날씨: 꽃/햇빛/산책 계열 연출
   - 나쁜 날씨: 대비형 톤 전환

### 확장 기능
1. **행동 추천 엔진**
2. **콘텐츠 연계 추천**
3. **개인화**

## 6. 사용자 흐름

### 첫 진입
1. 앱 설치 또는 위젯 추가
2. 위치 권한 허용
3. 선호 알림 시간 선택
4. 날씨 기반 추천 카드 첫 화면 노출
5. 위젯 고정

### 아침 사용 흐름
1. 위젯 확인
2. 오늘 날씨와 준비물 확인
3. 필요하면 앱으로 진입
4. 추천 콘텐츠 또는 행동 확인

### 하루 중 재방문 흐름
1. 상황 변화 알림 수신
2. 위젯 또는 앱 재진입
3. 추가 행동 확인

## 7. DAU/MAU를 높이기 위한 설계

### 반복 사용 유도 장치
- 아침 브리프 고정 노출
- 날씨 변동 알림
- 출발 전 리마인드
- 저녁 요약
- 연속 사용 보상(streak)
- 개인화된 추천 카드

### 목표 행동
- 사용자가 매일 아침 확인한다.
- 하루 중 적어도 3번은 다시 연다.
- 앱을 단순 조회용이 아니라 생활 루틴 도구로 인식한다.

## 10. 리스크 및 대응
1. 단순 날씨 앱으로 보일 위험 → 행동 추천 중심 UX 유지
2. 하루 1회 확인 후 끝날 위험 → 3회 터치포인트 운영
3. 알림 피로 위험 → 3개 알림만 정밀 운영
4. 콘텐츠 산만화 위험 → 우선순위/노출 규칙 고정
5. 개인화 부족 위험 → 초기 행동데이터 기반 점진적 개인화

## 11. 위젯 첫 화면 문구 후보
### 기본 톤
1. 오늘 챙길 것, 10초 만에 확인
2. 오늘 아침, 뭐 챙겨야 할지 대신 골라드려요
3. 지금 나가면 될까? 오늘의 출근/등교 브리프

### 토스 느낌
1. 오늘 나갈 때 챙길 것들
2. 오늘 아침 준비, 여기서 끝
3. 지금 확인하면 덜 잊어요

### 친근한 톤
1. 오늘 나갈 때 뭐 챙길지 같이 볼까요?
2. 아침 준비, 제가 먼저 체크해둘게요
3. 오늘도 바쁘죠. 챙길 것만 먼저 보여드릴게요

## 12. 알림 타이밍
1. 아침 고정 알림: 평일 07:30
2. 출발 전 알림: 아침 알림 후 30~60분
3. 저녁 예고 알림: 21:00~22:00

원칙: 알림은 3개로 제한하고, 아침 확인 → 낮 재진입 → 다음날 예고 흐름을 만든다.
